# RNN for Sentiment Analysis

## About the Project
This project explores sentiment analysis using a Recurrent Neural Network (RNN) and PyTorch. It uses the IMDB movie reviews dataset to prepare text data for sentiment classification.

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- PyTorch

## Project Workflow
1. Load the IMDB movie reviews dataset.
2. Check missing values and remove duplicate records.
3. Convert text to lowercase.
4. Remove URLs, punctuation, and HTML tags.
5. Remove stopwords and apply stemming.
6. Encode sentiment labels.
7. Convert text into numerical features using TF-IDF.
8. Split the dataset into training and testing sets.
9. Prepare data using PyTorch Dataset and DataLoader.
10. Define an RNN model for sentiment classification.

## Dataset
The project uses the IMDB Dataset containing movie reviews and their sentiment labels. Download the dataset and update the CSV file path according to your system.

## Objective
To understand text preprocessing and explore how Recurrent Neural Networks can be used for sentiment analysis.
